# US-Q.1 — Spec-first API

**Milestone:** cross-cutting (baseline in M1)
**Depends on:** —

**As a** developer (human or agent), **I want** every endpoint defined in
`splitkauf.openapi.yaml` before implementation, **so that** clients and server never
drift.

## Acceptance criteria

- Every new/changed endpoint exists in the spec before its implementation commit.

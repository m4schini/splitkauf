# US-L.2 — View all lists

**Milestone:** M1
**Depends on:** US-L.1

**As a** member, **I want** to see every list in the group, **so that** I can pick
the one relevant to my shop.

## Acceptance criteria

- All lists are visible to every authenticated member (no per-user ownership).
- Lists show name and a summary of open vs. checked items.

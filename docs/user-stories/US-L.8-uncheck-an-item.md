# US-L.8 — Uncheck an item

**Milestone:** M1
**Depends on:** US-L.7

**As a** member, **I want** to uncheck an item checked by mistake, **so that** it
returns to the open list.

## Acceptance criteria

- The item returns to the open section for all members.
- An uncheck is never silently dropped, even under concurrent edits.
- Unchecking is the same gesture as checking (tap the row in the "done"
  section) — no separate menu or confirmation (UX research §2).

# US-A.5 — Membership from the provider

**Milestone:** M2
**Depends on:** US-A.2

**As an** operator, **I want** group membership derived from the OIDC provider,
**so that** I manage users in one place (no in-app user management, per GOAL.md
non-goals).

## Acceptance criteria

- Every account known to the provider is a group member; no in-app membership
  administration exists.
